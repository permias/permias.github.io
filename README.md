# PERMIAS Nasional Website

Repository for the [PERMIAS Nasional website](https://www.permiasnasional.com/), built with [Astro](https://astro.build/) 🚀 and hosted on GitHub Pages.


Based on [AstroWind](https://github.com/onwidget/astrowind) template. Modified to use `pnpm` instead of `npm`.

Original commit SHA: `bbcbde87c92a631073e812bd672209effc49abc9`

To start developing:

1. Install `pnpm` using one of the methods described [here](https://pnpm.io/installation).
2. Run `pnpm run dev` to start a local development server.

Consider doing [Astro's tutorial](https://docs.astro.build/en/tutorial/) to get familiar with the framework.
